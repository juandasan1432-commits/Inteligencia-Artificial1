Preguntas de ejemplo

¿Qué hace console.log()?

Muestra mensajes y valores en la consola de JavaScript. Puedes abrirla desde las herramientas de desarrollo del navegador.

const total = 3 + 4;
console.log("Total:", total); // Total: 7
MDN · console.log()
¿Cómo se usa map() en JavaScript?

Aplica una función a cada elemento de un arreglo y devuelve un arreglo nuevo con los resultados.

const numeros = [2, 3, 4];
const dobles = numeros.map(numero => numero * 2);
console.log(dobles); // [4, 6, 8]
MDN · Array.prototype.map()
¿Cómo se imprime un mensaje en Java?

System.out.println() escribe un mensaje en la salida estándar y agrega un salto de línea.

public class Ejemplo {
    public static void main(String[] args) {
        System.out.println("Hola, Java");
    }
}
Oracle · PrintStream
¿En qué se diferencian JavaScript y TypeScript?

TypeScript añade tipos estáticos a JavaScript. Un compilador comprueba esos tipos y genera el JavaScript que se ejecuta.

function saludar(nombre: string): string {
  return "Hola, " + nombre;
}
Manual de TypeScript
¿Cómo se definen las funciones en Python?

def define una función con un nombre y sus parámetros. return devuelve un resultado al código que la llamó.

def sumar(a, b):
    return a + b

print(sumar(2, 3))  # 5

¿Cómo se previene XSS?

Cuando muestres texto de una persona, asigna el valor como texto. Si la aplicación admite HTML enriquecido, usa un sanitizador mantenido.

const mensaje = document.querySelector("#mensaje");
mensaje.textContent = textoDelUsuario;
OWASP · Prevención de XSS
¿Cómo funciona una lista enlazada en C++?

Una lista enlazada almacena valores en nodos conectados entre sí. std::list permite recorrerlos en ambos sentidos.

#include <list>

int main() {
    std::list<int> numeros{2, 3};
    numeros.push_front(1); // Resultado: 1, 2, 3
}
