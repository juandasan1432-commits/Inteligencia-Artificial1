# DevLibrary AI

Maqueta en español de una biblioteca conversacional sobre programación y ciberseguridad defensiva. La interfaz usa HTML y CSS con un logotipo SVG local.

## Uso

1. Abre `index.html` en un navegador o visita [el sitio publicado](https://juandasan1432-commits.github.io/Inteligencia-Artificial1/).
2. Selecciona una pregunta para ver su respuesta, un ejemplo de código y el enlace a la fuente.
3. Usa **Biblioteca** para consultar la documentación por tema. En **Estados** puedes ver la alerta de conexión y las demás situaciones de ejemplo.

Las respuestas están preparadas en HTML. La alerta de conexión es una demostración.

## Archivos

- [index.html](index.html) contiene la portada y las preguntas desplegables.
- [biblioteca.html](biblioteca.html) reúne la documentación oficial por tecnología.
- [estados.html](estados.html) muestra la conversación de ejemplo y las alertas.
- [css/styles.css](css/styles.css) organiza los estilos y el diseño adaptable.
- [Arquitectura](docs/architecture.md) y [estados](docs/ui-states.md) describen los componentes y cómo probarlos.
