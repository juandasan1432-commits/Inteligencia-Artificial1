# Estados de la interfaz

En **Chat**, abre una pregunta con clic, Enter o Espacio. En **Estados**, recorre los ejemplos mediante los enlaces de la galería.

| Estado | Dónde verlo | Contenido |
| --- | --- | --- |
| Respuesta | [Preguntas](../index.html#sugerencias) | Explicación, código de ejemplo y documentación. |
| Pensando | [Carga](../estados.html#carga) | Mensaje estático de una consulta pendiente. |
| Sin conexión | [Alerta](../estados.html#conexion) | Código `ERR_INTERNET_DISCONNECTED`, explicación y pasos para comprobar Wi-Fi o datos móviles. |
| Error | [Errores](../estados.html#error) | Ejemplos de generación, servicio, entrada y tiempo agotado. |
| Sin resultados | [Sin referencias](../estados.html#sin-resultados) | Orientación para reformular la consulta. |
| Entrada vacía | [Formulario](../estados.html#entrada-vacia) | Campo de muestra con ayuda contextual. |
| Conversación extensa | [Historial](../estados.html#extensa) | Mensajes y bloques de código con desplazamiento. |
| Fuentes | [Referencias](../estados.html#fuentes) | Enlaces a secciones de la documentación de Python. |
| Fuera de tema | [Alcance](../estados.html#fuera-de-tema) | Ejemplo de una redirección a temas técnicos. |

Para comprobar la maqueta, abre y cierra las preguntas con el teclado, visita **Sin conexión** y comprueba que el código aparezca en el panel de error. Repite en una ventana estrecha para revisar el foco y el desplazamiento de los bloques de código.
